# Reporting Guidelines — Dhaka Accessories (Simulated)

## Report Frequency
- Weekly: every Monday for the previous week
- Monthly: first Monday of the next month
- Campaign-specific: 1 day after a campaign ends

## Report Structure (6 Sections)
1. Executive Summary (3 lines max)
2. Key Metrics (WoW comparison)
3. Campaign Breakdown
4. Highlights (what worked)
5. Lowlights + Causes (what did not, and why)
6. Next Week Actions (specific, owned, dated)

## Writing Rules
- Always include at least one number per section
- "Lowlights" must include cause + data evidence
- "Actions" must be specific: not "improve creative" but "test review image vs product image for 7 days"
- Never blame team members — focus on what the data shows
- Keep total length to one page (or one screen)
- End every report with the disclaimer for this project

## WoW Calculation
`WoW % = (This Week − Last Week) ÷ Last Week × 100`

## Color Coding
- 🟢 Green: ≥ target
- 🟡 Yellow: within 10% of target
- 🔴 Red: below target by >10%

## Metrics to Always Report
- Spend
- Revenue
- Orders
- ROAS
- CPA
- CTR

## What to Never Do
- Never change multiple things in one week and report them together — you cannot tell what worked
- Never hide underperformance — data is data
- Never use jargon without a plain explanation (e.g., "ROAS — revenue per taka spent")
- Never claim real data in this simulated project
