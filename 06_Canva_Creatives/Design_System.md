# Dhaka Accessories — Design System (Simulated)

**Disclaimer:** This is a simulated design system for portfolio purposes.

## Brand Colors
| Name | Hex | Usage |
|---|---|---|
| Deep Maroon | #7B2D26 | Headlines, CTA buttons |
| Gold | #C9A227 | Accents, borders, price highlights |
| Cream | #FFF8E7 | Background |
| Charcoal | #2B2B2B | Body text |
| White | #FFFFFF | Space, contrast |

## Typography
- **Headline font:** Playfair Display (elegant, serif)
- **Body font:** Poppins (clean, sans-serif)
- Headline size: 48–64 px
- Body size: 24–32 px
- CTA size: 30–36 px, bold

## Logo Rules
- Text-based logo: "DHAN ACCESSORIES" in Playfair Display
- Always top-left, size 24 px
- Never stretch or recolor

## Ad Dimensions
| Placement | Size | Ratio |
|---|---|---|
| FB/IG Feed (square) | 1080×1080 | 1:1 |
| FB/IG Feed (portrait) | 1080×1350 | 4:5 |
| Story / Reel | 1080×1920 | 9:16 |

## Visual Rules
- Max 2 fonts per design
- Max 2–3 emojis
- Always include one number (price/days)
- CTA button always maroon with white text
- Leave 80 px safe margin on all sides
- One clear CTA per design

## Creative Types
1. **Product ad** — single product, headline, benefits, CTA
2. **Festival offer** — multi-product grid, price highlight, CTA
3. **Retargeting ad** — customer quote, social proof, urgency headline, CTA
