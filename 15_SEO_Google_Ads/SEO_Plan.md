# SEO Plan — Dhaka Accessories (Simulated)

**Disclaimer:** This is a planning document. No live website exists yet.

## Why SEO for Dhaka Accessories
When someone searches "kundan choker set dhaka", we want our product page to appear organically. SEO brings free, high-intent traffic that does not stop when ad budget runs out.

## The 3 Pillars of SEO

### 1. On-Page SEO
| Element | What to Do | Example |
|---|---|---|
| Page title | Product name + location, under 60 chars | "Kundan Choker Set — COD in Dhaka | Dhaka Accessories" |
| Meta description | Benefit + COD + delivery, under 155 chars | "Premium Kundan choker set at 650 BDT. Cash on delivery, 2-day delivery in Dhaka, 7-day return." |
| H1 heading | Product name, clear | "Kundan Choker Set" |
| Product description | 150–300 words, answers buyer questions | What it is, material, who it is for, care instructions |
| Image alt text | Describe the image accurately | "Kundan choker set with gold stones on cream background" |
| URL slug | Short, keyword-first | /kundan-choker-set/ |

### 2. Technical SEO (when website exists)
- Mobile-friendly design (most BD shoppers use mobile)
- Page load under 3 seconds
- Clean URL structure
- Sitemap submitted to Google Search Console
- Working links, no broken pages

### 3. Off-Page SEO
- Influencer collaborations (Day 27)
- Brand mentions on Facebook groups
- Customer reviews and testimonials
- Backlinks from local fashion blogs (future)

## SEO Rules
- One keyword theme per page — do not stuff multiple keywords [citation:2]
- Match page type to search intent (product page for transactional, blog for informational) [citation:2][citation:11]
- Write for humans first, search engines second
- Never keyword-stuff — it hurts ranking and reads badly
- Update product descriptions every season
