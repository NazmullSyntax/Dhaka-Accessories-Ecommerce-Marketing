# CapCut Editing Guide (Free Version)

## Setup
1. Download CapCut from capcut.com (desktop) or app store
2. Create new project
3. Aspect ratio: 9:16
4. Import clips from phone/computer

## Editing Steps
1. **Trim** — cut out shaky or dark parts
2. **Order** — hook first, product second, CTA last
3. **Jump cuts** — cut every 2–3 sec to keep pace
4. **Text overlays** — add 3+ text: hook, benefit, CTA
5. **Music** — add from CapCut library, set volume 30–50%
6. **Transitions** — quick fades only, no flashy effects
7. **Export** — 1080 × 1920, MP4

## Free Version Limits
- No premium templates
- Some music requires premium (choose free library tracks)
- No export watermark for free tracks

## Quality Checks
- [ ] Hook appears at 0 sec
- [ ] Text readable on mobile
- [ ] No text below safe margin
- [ ] Audio balanced
- [ ] Duration under 30 sec
- [ ] Exported at 1080 × 1920
