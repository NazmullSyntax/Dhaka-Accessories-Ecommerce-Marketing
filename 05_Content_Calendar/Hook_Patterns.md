# Hook Patterns for Dhaka Accessories

## Pattern 1: Question Hook
"বিয়ের গয়না নিয়ে চিন্তায় আছেন?"
"কতবার ভেবেছেন — এই দামে ভালো গয়না পাওয়া যাবে?"

## Pattern 2: Problem Hook
"দামি দোকানে গিয়ে গয়না দেখতে দেখতে ক্লান্ত?"
"ল্যাপটপ আর বই একসাথে বহন করতে পারছেন না?"

## Pattern 3: Number Hook
"৬৫০ টাকায় premium look — বিশ্বাস হচ্ছে না?"
"২ দিনে delivery, COD সুবিধা — ঢাকার ভেতরে।"

## Pattern 4: Curiosity Hook
"এই সেটটা কেন সবাই চাইছে জানেন?"
"ঢাকার মেয়েরা এখন এই ডিজাইনটাই খুঁজছে।"

## Pattern 5: Direct Benefit Hook
"COD-এ অর্ডার করুন, ৭ দিনের return policy।"
"Student-friendly ব্যাগ — ল্যাপটপসহ সব ঢোকে।"
