## Budget Rules
- Start with 50–70% of target daily budget for first 3 days (learning phase)
- Increase by max 20% per day if CPA is below target
- Pause ad set if CPA is 2x target for 3 consecutive days
- For 11.11 use Lifetime budget (6,000 BDT) with end date
- For ongoing campaigns use Daily budget
