## Key Gaps We Can Exploit
1. **Video content:** None of the direct competitors uses reels consistently. We can win with short video.
2. **Fast delivery:** We can promise 2–3 days inside Dhaka, faster than Daraz.
3. **Transparent pricing:** We can show COD and return policy clearly — Daraz sellers often hide delivery cost until checkout.
4. **Bundle offers:** Neither direct competitor pushes bundles. We can increase AOV with bundle offers.
